Pindiz player records

A simple record dashboard for the Pindiz PSL squad. It stores each player's recent PSL matches (up to 10, from the last two years) and shows them as profiles, tables and findings.

What is on this website

  • Players: every player's records and form. Compare 2 players, add or remove players.
  • Entry Form: the demonstration form for a match record.
  • Findings: what our SQL queries found in the data.

Run the backend (python backend/app.py) to use the Players page.

Data: ESPNcricinfo Statsguru (Nov 2026). Student project, not an official Pindiz website.
